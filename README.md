🎵 VibeSynth VST3
A lightweight, experimental VST3 plugin that turns text prompts into synth sounds on the fly using a dynamic oscillator-based engine.

✨ Features
Prompt-to-Sound Engine: Describe the sound or vibe you want in plain English, and watch the plugin translate your text into custom synth parameters.

Oscillator-Based Architecture: Generates rich, organic tones powered by flexible, real-time internal oscillator processing rather than heavy sample playback.

VST3 Standard: Fully compatible with any modern DAW that supports VST3 plugins (Ableton Live, FL Studio, Reaper, Logic via wrappers, etc.).

Zero Bloat: Lightweight, fast, and built purely for creative experimentation.

🚀 Quick Start
Download the latest compiled .vst3 binary from the Releases page.

Place it into your system's VST3 plugin directory:

Windows: C:\Program Files\Common Files\VST3

macOS: /Library/Audio/Plug-Ins/VST3

Rescan your DAW's plugin library, load it onto a MIDI track, type in your prompt, and start playing!
